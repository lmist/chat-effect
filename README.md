# chat-effect

A Vercel-hosted web chat built on the [Chat SDK](https://github.com/vercel/chat) (`npm i chat`).

This repo vendors the Chat SDK source as a git subtree at `repos/effect` and the [shadcn chatbot kit](https://github.com/Blazity/shadcn-chatbot-kit) at `repos/shadcn-chatbot-kit`.

Agent instructions live in [AGENTS.md](./AGENTS.md).
